# Contributing

Thanks for helping improve Freeloaders Archive!

This project is a collection of free tools, credits, licenses, discounts and other useful offers. Contributions are welcome, especially when they add something genuinely useful to the archive.

## Guidelines

Please keep the following in mind when opening a pull request:

* Include a short description of the offer you're adding.
* Use the official claim or offer link whenever possible.
* If you're changing a section heading, update the Contents list too.
* If you're adding a new section, give it a clear and unique name.
* Keep one change or one type of change per pull request where possible. This makes changes easier to review.
* Make sure the offer is still active and available before submitting it.
* Include useful eligibility details, limits, expiration dates or other important conditions when known.
* Do not add links to tools or sites focused on adult content or pornography.
* Do not add misleading, expired or unverifiable offers.

## Updating Your Pull Request

If something needs to be changed before your pull request can be merged, you don't need to open a new one.

Simply update your existing pull request with the requested changes. If you're unsure how to update a pull request, GitHub's documentation covers the process.

Thanks for helping keep the archive useful and up to date!
